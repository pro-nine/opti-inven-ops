# Data Platform Upgrade

This adds an end-to-end data platform layer without changing the six existing analytical modules.

## Flow

```text
data/demand_weekly.csv
 -> ingestion and wide-to-long transformation
 -> quality checks
 -> existing Modules 1–6 run unchanged
 -> newly generated analytics CSVs are loaded into DuckDB
 -> run_log and output manifest are written
 -> all DuckDB tables are exported for Power BI
```

## Core tables

- `raw_demand`: original source data.
- `demand`: long-format `date`, `sku`, `demand` table.
- `demand_summary`: SKU-level demand profile.
- Analytics tables: CSV outputs generated by the existing modules.
- `run_log`: run ID, status, row counts, duration, and error field.

## Run

```bash
pip install -r requirements-data-platform.txt
python -m data_platform.pipeline
pytest -q
```

The existing analytical modules are not modified. The adapter calls `src.run_all`, discovers newly generated CSV outputs, loads them into DuckDB, and exports all tables under `data/powerbi/` for Power BI.
